# ЛР1. Задача №13. Сортировка выбором

**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.
**Модуль:** 33-Babkin. **Баллы за задачу:** 2.

## Условие и формат ввода-вывода

Отсортировать массив по неубыванию вручную методом выбора минимума. Встроенная сортировка в решении не используется. Массив изменяется на месте; алгоритмический метод допускает пустой массив и один элемент.

Сначала вводится n, затем n элементов. Выводится отсортированный массив через пробел.

Длина каждого вводимого массива — от 2 до 99999 включительно; элементы имеют тип int.
Пробелы и переводы строк равнозначны. Приглашения к вводу не печатаются.
Передавать null в алгоритмический метод нельзя.

## Реализация и выбор структуры данных

Используется обычный массив int[]: его длина известна при чтении, доступ по индексу выполняется
за O(1). Ввод и вывод вынесены в общий класс ConsoleInput. Алгоритм доступен отдельным методом
для тестирования, а метод main обеспечивает консольный запуск.

## Идея, корректность и ручные проверки

**Идея.** Для каждой позиции находится минимум неотсортированного суффикса и меняется местами
с элементом этой позиции. Алгоритм написан вручную, встроенная сортировка не используется.

**Корректность.** Перед шагом с номером `i` префикс `[0, i)` уже отсортирован и содержит `i`
наименьших элементов. Перенос минимума суффикса на позицию `i` расширяет правильный префикс
на один элемент. После последнего шага весь массив отсортирован. Каждый шаг является обменом,
поэтому значения и число повторов сохраняются. Устойчивость сортировки выбором не гарантируется
и для этой задачи не требуется.

| Массив | Результат | Что проверяет |
|---|---|---|
| `[5, 2, 4, 1]` | `[1, 2, 4, 5]` | Несколько переносов минимума |
| `[3, -1, 3, 0, -1]` | `[-1, -1, 0, 3, 3]` | Отрицательные числа и сохранение повторов |
| `[1, 2]` | `[1, 2]` | Уже отсортированный массив минимальной допустимой длины |

## Время и память

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n²) |
| Вспомогательная память алгоритма без входа и результата | O(1) |
| Память нового результата | В исходном массиве |
| Время всей консольной программы | Θ(n²) |
| Память всей консольной программы | Θ(n) |

n — длина массива; i — текущая позиция внешнего цикла.
