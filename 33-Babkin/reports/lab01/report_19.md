# ЛР1. Задача №19. Объединение двух отсортированных массивов

**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.
**Модуль:** 33-Babkin. **Баллы за задачу:** 2.

## Условие и формат ввода-вывода

Объединить два неубывающих массива за O(n + m), сохранив повторы. Возвращается новый массив, исходные массивы не изменяются. Отсортированность — предусловие: повторная сортировка не выполняется. Алгоритмический метод допускает пустые входные массивы.

Вводятся два блока подряд: n и n элементов первого массива, затем m и m элементов второго. Каждый массив должен быть отсортирован по неубыванию. Выводится результат слияния через пробел.

Длина каждого вводимого массива — от 2 до 99999 включительно; элементы имеют тип int.
Пробелы и переводы строк равнозначны. Приглашения к вводу не печатаются.
Передавать null в алгоритмический метод нельзя.

## Идея, корректность и ручные проверки

**Идея.** Два индекса указывают на первые ещё не использованные элементы входов. Меньший
элемент переносится в новый массив, а соответствующий индекс увеличивается. При равенстве
берётся элемент первого массива. Когда один вход закончился, остаток другого дописывается целиком.

**Корректность.** Заполненный префикс результата отсортирован и содержит наименьшие уже
извлечённые элементы обоих входов. Поскольку каждый вход упорядочен, меньше двух текущих
элементов среди оставшихся быть не может. Выбор меньшего сохраняет инвариант. Каждый элемент
переносится ровно один раз, поэтому дубликаты и все исходные значения сохраняются.

| Первый массив; второй массив | Результат | Что проверяет |
|---|---|---|
| `[1, 4, 7]`; `[2, 4, 8]` | `[1, 2, 4, 4, 7, 8]` | Чередование источников и равные значения |
| `[-5, -2]`; `[0, 3, 8]` | `[-5, -2, 0, 3, 8]` | Первый массив закончился раньше |
| `[0, 3, 8]`; `[-5, -2]` | `[-5, -2, 0, 3, 8]` | Второй массив закончился раньше |

## Время и память

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n + m) |
| Вспомогательная память алгоритма без входа и результата | O(1) |
| Память нового результата | Θ(n + m) |
| Время всей консольной программы | Θ(n + m) |
| Память всей консольной программы | Θ(n + m) |

n и m — длины первого и второго массивов.
