# ЛР1. Задача №43. Перемещение нулей в конец

**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.
**Модуль:** 33-Babkin. **Баллы за задачу:** 2.

## Условие и формат ввода-вывода

Переместить все нули в конец того же массива, сохранив взаимный порядок остальных элементов. Преобразование выполняется на месте, новый массив не создаётся. Алгоритмический метод допускает пустой массив и один элемент.

Сначала вводится n, затем n элементов. Выводится преобразованный массив через пробел.

Длина каждого вводимого массива — от 2 до 99999 включительно; элементы имеют тип int.
Пробелы и переводы строк равнозначны. Приглашения к вводу не печатаются.
Передавать null в алгоритмический метод нельзя.

## Реализация и выбор структуры данных

Используется обычный массив int[]: его длина известна при чтении, доступ по индексу выполняется
за O(1). Ввод и вывод вынесены в общий класс ConsoleInput. Алгоритм доступен отдельным методом
для тестирования, а метод main обеспечивает консольный запуск.

## Идея, корректность и ручные проверки

**Идея.** Индекс записи указывает на следующую свободную позицию для ненулевого числа.
При проходе слева направо каждое ненулевое значение записывается в эту позицию, затем индекс
увеличивается. После прохода оставшийся хвост заполняется нулями.

**Корректность.** Записанный префикс всегда содержит ровно ненулевые элементы просмотренной
части в исходном порядке. Индекс записи не опережает просмотр, поэтому запись не уничтожает
ещё не прочитанные числа. В конце длина префикса равна количеству ненулевых элементов;
заполнение остальных позиций нулями сохраняет состав массива.

| Массив | Результат | Что проверяет |
|---|---|---|
| `[0, 3, 0, -1, 5]` | `[3, -1, 5, 0, 0]` | Удаление промежутков и сохранение порядка |
| `[0, 0]` | `[0, 0]` | Нет ненулевых чисел |
| `[-2, 4, -1]` | `[-2, 4, -1]` | Нет нулей, исходный порядок сохраняется |

## Время и память

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n) |
| Вспомогательная память алгоритма без входа и результата | O(1) |
| Память нового результата | В исходном массиве |
| Время всей консольной программы | Θ(n) |
| Память всей консольной программы | Θ(n) |

n — длина массива; r — количество ненулевых элементов.
