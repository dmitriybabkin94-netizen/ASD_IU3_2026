# ЛР1. Задача №7. Второй максимум

**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.
**Модуль:** 33-Babkin. **Баллы за задачу:** 1.

## Условие и формат ввода-вывода

Найти второй по величине элемент. По условию все элементы различны. Реализация дополнительно поддерживает повторы и возвращает второй различный максимум; при отсутствии двух различных значений выбрасывает IllegalArgumentException. Исходный массив не изменяется.

Сначала вводится n, затем n элементов массива. Выводится одно число — второй максимум.

Длина каждого вводимого массива — от 2 до 99999 включительно; элементы имеют тип int.
Пробелы и переводы строк равнозначны. Приглашения к вводу не печатаются.
Передавать null в алгоритмический метод нельзя.

## Реализация и выбор структуры данных

Используется обычный массив int[]: его длина известна при чтении, доступ по индексу выполняется
за O(1). Ввод и вывод вынесены в общий класс ConsoleInput. Алгоритм доступен отдельным методом
для тестирования, а метод main обеспечивает консольный запуск.

Решение: [SecondMaximum.java](../../src/main/java/ru/bmstu/lab1/task_7/SecondMaximum.java).
Тесты: [SecondMaximumTest.java](../../src/test/java/ru/bmstu/lab1/task_7/SecondMaximumTest.java).

## Идея, корректность и ручные проверки

**Идея.** За один проход поддерживаются максимум обработанного префикса и наибольшее значение,
строго меньшее этого максимума. Когда встречается новый максимум, прежний максимум становится
вторым. Иначе число может улучшить только второй максимум. Равное максимуму значение пропускается.
Наличие второго значения хранится отдельным флагом, поэтому `Integer.MIN_VALUE` не используется
как признак отсутствия ответа и корректно обрабатывается как обычное число.

**Корректность.** После каждого шага две переменные содержат два наибольших различных значения
обработанного префикса, если они существуют. Описанные переходы сохраняют этот инвариант.
После обработки всего массива второе значение является искомым.

**Ручные проверки с ожидаемыми результатами.**

| Массив | Ответ | Что проверяет |
|---|---:|---|
| `[5, 1, 9, 3, 7]` | `7` | Новый максимум и последующее улучшение второго |
| `[-5, -2, -8]` | `-5` | Все числа отрицательны; начальное значение 0 не должно стать ответом |
| `[-2147483648, 2147483647]` | `-2147483648` | Два элемента и обе границы `int` |
| `[9, 9, 7, 7]` | `7` | Дополнительный случай: повтор максимума не считается вторым значением |

## Время и память

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n) |
| Вспомогательная память алгоритма без входа и результата | O(1) |
| Память нового результата | O(1), одно число |
| Время всей консольной программы | Θ(n) |
| Память всей консольной программы | Θ(n) |

n — длина массива.
