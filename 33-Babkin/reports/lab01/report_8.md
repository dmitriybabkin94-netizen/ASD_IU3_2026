## Условие и формат ввода-вывода

Выделить положительные и отрицательные элементы в два новых массива, сохранив их исходный порядок. Нули не включать. Исходный массив не изменяется. Результат хранится в SignGroups; алгоритмический метод допускает пустой массив.

Сначала вводится n, затем n элементов. Выводятся две строки: положительные числа и отрицательные числа. Внутри строки числа разделены пробелами; для отсутствующей группы выводится пустая строка.

Длина каждого вводимого массива — от 2 до 99999 включительно; элементы имеют тип int.
Пробелы и переводы строк равнозначны. Приглашения к вводу не печатаются.
Передавать null в алгоритмический метод нельзя.

## Реализация и выбор структуры данных

Используется обычный массив int[]: его длина известна при чтении, доступ по индексу выполняется
за O(1). Ввод и вывод вынесены в общий класс ConsoleInput. Алгоритм доступен отдельным методом
для тестирования, а метод main обеспечивает консольный запуск.

## Идея, корректность и ручные проверки

**Идея.** Первый проход подсчитывает `p` положительных и `q` отрицательных чисел. Затем создаются
два массива точного размера. Второй проход записывает числа в соответствующие массивы слева
направо; нули пропускаются. Оба массива возвращаются в `SignGroups`.

**Корректность.** После обработки очередного префикса в результатах находятся в исходном порядке
ровно его положительные и отрицательные элементы. Новое число добавляется только в конец своей
группы, поэтому порядок сохраняется. Подсчёт на первом проходе гарантирует достаточный размер.

| Массив | Положительные; отрицательные | Что проверяет |
|---|---|---|
| `[0, 3, -1, 0, 2, -5]` | `[3, 2]`; `[-1, -5]` | Обе группы, исключение нулей и сохранение порядка |
| `[4, 2]` | `[4, 2]`; `[]` | Пустая отрицательная группа |
| `[0, 0]` | `[]`; `[]` | Две пустые группы; программа печатает две пустые строки |

## Время и память

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n) |
| Вспомогательная память алгоритма без входа и результата | O(1) |
| Память нового результата | O(p + q) + O(1) |
| Время всей консольной программы | Θ(n) |
| Память всей консольной программы | Θ(n) |

n — длина массива; p и q — количества положительных и отрицательных элементов, p + q ≤ n.
