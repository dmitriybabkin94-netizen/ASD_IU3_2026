# ЛР1. Задача №34. Максимальная сумма подмассива

**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.

## Условие и формат ввода-вывода

Найти максимальную сумму непустого непрерывного подмассива алгоритмом Кадане за O(n). Для полностью отрицательного массива ответом является наибольший элемент. Суммы вычисляются в long. Исходный массив не изменяется; пустой массив отклоняется.

Сначала вводится n, затем n элементов. Выводится одно число типа long — максимальная сумма непрерывного непустого участка.

Длина каждого вводимого массива — от 2 до 99999 включительно; элементы имеют тип int.
Пробелы и переводы строк равнозначны. Приглашения к вводу не печатаются.
Передавать null в алгоритмический метод нельзя.

## Идея, корректность и ручные проверки

**Идея.** Алгоритм Кадане хранит `endingHere` — лучшую сумму непустого участка, заканчивающегося
в текущем элементе, и `best` — лучшую сумму среди всех уже рассмотренных участков.
Для очередного `a[i]` выполняется переход
`endingHere = max(a[i], endingHere + a[i])`, затем `best = max(best, endingHere)`.

**Корректность.** Любой участок, заканчивающийся в `i`, либо состоит из одного `a[i]`, либо
продолжает участок с концом в `i - 1`. Среди продолжений достаточно лучшего предыдущего.
Это доказывает переход; переменная `best` учитывает каждый возможный правый конец.
Обе суммы инициализируются первым числом, поэтому для полностью отрицательного массива
выбирается наибольший элемент, а не пустой участок с суммой 0.

| Массив | Ответ | Что проверяет |
|---|---:|---|
| `[-2, 3, -1, 4, -5]` | `6` | Лучший участок `[3, -1, 4]` расположен внутри массива |
| `[-5, -2, -8]` | `-2` | Запрет пустого участка |
| `[2147483647, 2147483647]` | `4294967294` | Сумма больше максимального `int` |
| `[0, 0]` | `0` | Нулевая сумма непустого участка |

## Время и память

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n) |
| Вспомогательная память алгоритма без входа и результата | O(1) |
| Память нового результата | O(1), одно число |
| Время всей консольной программы | Θ(n) |
| Память всей консольной программы | Θ(n) |

n — длина массива.
