# Расчёт асимптотики. ЛР1, задача №43 — Перемещение нулей в конец

**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.

## Обозначения и модель оценки

n — длина массива; r — количество ненулевых элементов.

T — время работы, S — вспомогательная память алгоритма. O — верхняя асимптотическая оценка,
Θ — точный порядок роста. Доступ по индексу и операции с int и long считаются O(1).
Входные массивы и память нового результата учитываются отдельно от вспомогательных переменных.
Оценки приведены для допустимых входных данных.

## Расчёт времени и памяти алгоритма

Файл: [ZeroMover.java](../../src/main/java/ru/bmstu/lab1/task_43/ZeroMover.java).

Первый цикл читает все `n` элементов. Обозначим количество ненулевых значений через `r`:
в этом цикле выполняется `r` записей. Второй цикл записывает `n - r` нулей.
Следовательно, суммарно производится `n` чтений и `r + (n - r) = n` записей.

Отсюда `T(n) = Θ(n)`, в том числе для массива без нулей или состоящего только из нулей.

Индекс записи и текущее значение занимают фиксированный объём: `S(n) = O(1)`.
Результат размещается в исходном массиве, отдельный выходной массив не выделяется.

## Время и память всей программы

Входной массив занимает Θ(n), алгоритм использует O(1) вспомогательной памяти. ConsoleInput.printArray формирует строку в StringBuilder за O(n) времени и памяти. Чтение, преобразование и вывод линейны. Полная программа: Θ(n) времени и Θ(n) памяти.

Чтение и вывод одного числа int или long считаются O(1), поскольку длина его записи ограничена.

## Итог

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n) |
| Вспомогательная память без входа и результата | O(1) |
| Память нового результата | В исходном массиве |
| Время всей программы с вводом и выводом | Θ(n) |
| Память всей программы с входом, результатом и выводом | Θ(n) |
