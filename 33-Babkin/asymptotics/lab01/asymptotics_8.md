## Обозначения и модель оценки

n — длина массива; p и q — количества положительных и отрицательных элементов, p + q ≤ n.

T — время работы, S — вспомогательная память алгоритма. O — верхняя асимптотическая оценка,
Θ — точный порядок роста. Доступ по индексу и операции с int и long считаются O(1).
Входные массивы и память нового результата учитываются отдельно от вспомогательных переменных.
Оценки приведены для допустимых входных данных.

## Расчёт времени и памяти алгоритма

Файл: [SignFilter.java](../../src/main/java/ru/bmstu/lab1/task_8/SignFilter.java).

Первый проход обрабатывает `n` элементов и подсчитывает размеры двух групп.
Выделение и начальная инициализация массивов длины `p` и `q` требуют `O(p + q)` времени.
Второй проход снова рассматривает `n` элементов и записывает в результат `p + q` чисел.

Таким образом, `T(n) = Θ(n) + O(p + q) + Θ(n) = Θ(n)`, поскольку `p + q ≤ n`.

Счётчики и индексы занимают `O(1)` вспомогательной памяти. Массивы результата требуют
`O(p + q)` памяти, объект `SignGroups` — `O(1)`. С учётом результата дополнительная память
в худшем случае равна `O(n)`. Исходный массив не меняется.

## Время и память всей программы

Вход занимает Θ(n), два массива результата — O(p + q), объект SignGroups — O(1). Для вывода каждой группы ConsoleInput.printArray создаёт StringBuilder; суммарный объём форматируемых данных не превышает O(p + q). Чтение и обработка занимают Θ(n), вывод — O(p + q). Полная программа: Θ(n) времени и Θ(n) памяти.

Чтение и вывод одного числа int или long считаются O(1), поскольку длина его записи ограничена.

## Итог

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n) |
| Вспомогательная память без входа и результата | O(1) |
| Память нового результата | O(p + q) + O(1) |
| Время всей программы с вводом и выводом | Θ(n) |
| Память всей программы с входом, результатом и выводом | Θ(n) |
