**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.

## Обозначения и модель оценки

n — длина массива; k — число позиций сдвига; s = k % n при n > 0; floor(x) — округление вниз.

T — время работы, S — вспомогательная память алгоритма. O — верхняя асимптотическая оценка,
Θ — точный порядок роста. Доступ по индексу и операции с int и long считаются O(1).
Входные массивы и память нового результата учитываются отдельно от вспомогательных переменных.
Оценки приведены для допустимых входных данных.

## Расчёт времени и памяти алгоритма

Файл: [LeftRotation.java](../../src/main/java/ru/bmstu/lab1/task_38/LeftRotation.java).

Нормализация `s = k % n` занимает `O(1)`, так как `k` имеет фиксированный тип `long`.
Если массив пуст или `s = 0`, метод завершится за `O(1)` без разворотов.

При `0 < s < n` разворачиваются две части длины `s` и `n - s`, затем весь массив длины `n`.
Разворот участка длины `l` выполняет `floor(l / 2)` обменов. Общее число обменов:

C(n, s) = floor(s / 2) + floor((n - s) / 2) + floor(n / 2) ≤ n.

В частности, последний разворот уже требует `Θ(n)` операций. Поэтому для ненулевого
нормализованного сдвига время равно `Θ(n)`, общий верхний предел — `O(n)`.
Количество полных оборотов в `k` не увеличивает число итераций.

Используются индексы, сдвиг и временное число для обмена: `S(n) = O(1)`.
Метод разворота вызывается последовательно и не рекурсивно. Новый массив не создаётся.

## Время и память всей программы

Входной массив занимает Θ(n). Тройной разворот использует O(1) дополнительной памяти; ConsoleInput.printArray создаёт StringBuilder за O(n) памяти. Чтение и вывод требуют Θ(n) времени даже при s = 0. Поэтому полное время и полная память программы равны Θ(n). Требование O(1) дополнительной памяти выполнено для самого преобразования массива.

Чтение и вывод одного числа int или long считаются O(1), поскольку длина его записи ограничена.

## Итог

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | O(n); при s = 0 — O(1) |
| Вспомогательная память без входа и результата | O(1) |
| Память нового результата | В исходном массиве |
| Время всей программы с вводом и выводом | Θ(n) |
| Память всей программы с входом, результатом и выводом | Θ(n) |
