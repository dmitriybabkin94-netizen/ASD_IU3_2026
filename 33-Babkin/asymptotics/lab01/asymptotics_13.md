## Обозначения и модель оценки

n — длина массива; i — текущая позиция внешнего цикла.

T — время работы, S — вспомогательная память алгоритма. O — верхняя асимптотическая оценка,
Θ — точный порядок роста. Доступ по индексу и операции с int и long считаются O(1).
Входные массивы и память нового результата учитываются отдельно от вспомогательных переменных.
Оценки приведены для допустимых входных данных.

## Расчёт времени и памяти алгоритма

Файл: [SelectionSort.java](../../src/main/java/ru/bmstu/lab1/task_13/SelectionSort.java).

Внешний цикл выбирает позиции от `0` до `n - 2`. Для позиции `i` внутренний цикл сравнивает
оставшиеся `n - i - 1` элементов с текущим минимумом. Общее число сравнений элементов:

C(n) = (n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2.

Для каждой из `n - 1` позиций выполняется один обмен за `O(1)`. Поэтому
`T(n) = Θ(n(n - 1) / 2) + O(n) = Θ(n²)`.
Количество сравнений не зависит от начального порядка: оценка одинакова для лучшего
и худшего случаев, включая уже отсортированный массив.

Индексы и временное значение при обмене занимают `O(1)` памяти. Сортировка выполняется
в исходном массиве: `S(n) = O(1)`, новый массив результата не нужен.

## Время и память всей программы

Входной массив занимает Θ(n). Сортировка изменяет его на месте за O(1) вспомогательной памяти. ConsoleInput.printArray дополнительно создаёт StringBuilder за O(n) памяти и времени. Чтение также линейно. Полное время Θ(n²) + O(n) = Θ(n²), полная память Θ(n).

Чтение и вывод одного числа int или long считаются O(1), поскольку длина его записи ограничена.

## Итог

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n²) |
| Вспомогательная память без входа и результата | O(1) |
| Память нового результата | В исходном массиве |
| Время всей программы с вводом и выводом | Θ(n²) |
| Память всей программы с входом, результатом и выводом | Θ(n) |
