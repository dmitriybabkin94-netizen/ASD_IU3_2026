# Расчёт асимптотики. ЛР1, задача №19 — Объединение двух отсортированных массивов

**Выполнил:** Бабкин Дмитрий Витальевич, группа ИУ3-33Б.

## Обозначения и модель оценки

n и m — длины первого и второго массивов.

T — время работы, S — вспомогательная память алгоритма. O — верхняя асимптотическая оценка,
Θ — точный порядок роста. Доступ по индексу и операции с int и long считаются O(1).
Входные массивы и память нового результата учитываются отдельно от вспомогательных переменных.
Оценки приведены для допустимых входных данных.

## Расчёт времени и памяти алгоритма

Файл: [SortedMerge.java](../../src/main/java/ru/bmstu/lab1/task_19/SortedMerge.java).

Хотя в коде три цикла, они не вложены друг в друга. В первом цикле на каждом шаге увеличивается
ровно один из двух входных индексов. Два следующих цикла дописывают ещё не перенесённые
элементы. Каждый из `n + m` элементов записывается ровно один раз.

Создание результата длины `n + m` и его заполнение требуют `Θ(n + m)` времени.
Итого `T(n, m) = Θ(n + m)`.

Три индекса занимают `O(1)` вспомогательной памяти. Новый выходной массив занимает
`O(n + m)` памяти, поэтому с учётом результата дополнительная память равна `O(n + m)`.
Входные массивы не копируются и не меняются.

## Время и память всей программы

Два входных массива, новый результат и строка вывода имеют суммарный размер Θ(n + m). Чтение, слияние и вывод линейны относительно n + m. Поэтому полная программа использует Θ(n + m) времени и Θ(n + m) памяти.

Чтение и вывод одного числа int или long считаются O(1), поскольку длина его записи ограничена.

## Итог

| Что оценивается | Оценка |
|---|---|
| Время алгоритма | Θ(n + m) |
| Вспомогательная память без входа и результата | O(1) |
| Память нового результата | Θ(n + m) |
| Время всей программы с вводом и выводом | Θ(n + m) |
| Память всей программы с входом, результатом и выводом | Θ(n + m) |
